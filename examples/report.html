Introduction

This report is Markdown with Clay chunks. Each chunk runs, and the report shows its code, what it printed and its figure. Inline code, links (also to a heading: the math) and bold italics work too.

  • chunks share variables, like one script
  • output is captured with Console capture
    • nested items are indented
  • figures come from the plot brick

Data

xs = (0..40) map { |i| i / 4.0 }
ys = xs map { |x| Math sin(x) * Math exp(0 - x / 6) }
("points: " + xs size toString) println
("peak: " + (ys reduce(0) { |m, y| Math max(m, y) }) toString) println
points: 41
peak: 0.77684987

The data has 41 points and peaks at 0.777. The next chunk plots it, as Figure 1.

Plot figure(#{figsize: [6, 3]})
Plot plot(xs, ys, #{label: "damped sine"})
Plot title("A damped sine")
Plot xlabel("x"); Plot legend; Plot grid(true)

Math

Math goes between dollar signs, in TeX's notation: the curve above is y = sin(x)  e−x/6, it peaks at x ≈ 1.4, and the mean squared error of a fit is

MSE = 1/n ∑i=1n (yi − yi)2

Sets and logic work too: ∀ ε > 0 ∃ δ, x ∈ ℝ, A ∪ B ⊆ C. Prices like $5 and $10 stay text, as does $x$.
